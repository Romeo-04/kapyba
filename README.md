# KapyBa

Team Kapybytes, CSSPRINT 2026 ("The Tale is Forged"). A free, capybara-guided app where karinderya customers rate dishes in two taps, owners get private coaching and a smarter shopping list, and students and workers see which dishes are worth their money.
